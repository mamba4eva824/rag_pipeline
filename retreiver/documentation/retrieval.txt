# Confluence Retrieval System with LangChain: Technical Documentation
# Date: May 8, 2025

## Overview
The retrieval.py script implements a semantic search system enhanced with LangChain that converts natural language queries into vector embeddings and retrieves the most relevant Confluence content chunks from a Pinecone vector database.

## System Components

1. SentenceTransformer Model
   - Uses "all-MiniLM-L6-v2" model to embed queries
   - Produces 384-dimensional embeddings matching the document embeddings
   - Now wrapped in LangChain's Embeddings interface for better compatibility
   - Runtime output: "Loaded model: all-MiniLM-L6-v2"

2. Pinecone Vector Database Connection
   - Connects to the "confluence-founders" index
   - Uses API key stored in environment variables
   - Now provides both direct Pinecone API access and LangChain's PineconeVectorStore
   - Runtime output: "Connected to Pinecone index: confluence-founders"

3. ConfluenceRetriever Class
   - Main class handling the retrieval process
   - LangChain integration through PineconeVectorStore
   - Methods:
     - search_langchain(): Retrieves results using LangChain's similarity search
     - search_hybrid(): Uses hybrid retrieval (dense + sparse) if available
     - encode_query(): Converts query text to vector embeddings
     - retrieve(): Legacy method to access Pinecone API directly
     - search(): Main entry point, with options for different search methods

## Workflow

1. Query Embedding
   - User query is embedded using LangChain's Embeddings interface
   - Wrapped SentenceTransformer model ensures compatibility

2. Vector Search Options
   - Standard LangChain search: Using similarity_search
   - Hybrid search: Using similarity_search_with_score when supported
   - Legacy search: Direct access to Pinecone API for backward compatibility
   - Embeddings compared using cosine similarity in all methods

3. Result Processing
   - Results sorted by similarity score (descending)
   - LangChain Documents converted to consistent format
   - Each result contains:
     - Similarity score (e.g., 0.4459)
     - Document ID (e.g., "5308428-3")
     - Metadata (title, URL, content excerpt, etc.)

4. Output Format
```
--- Result 1 (Score: 0.4459) ---
ID: 5308428-3
Title: Branding, Marketing, & Investors
URL: https://ohmgym.atlassian.net/wiki/spaces/Founders/pages/5308428
Excerpt: - *Investors ** - We plan to operate at a low profit margin to gain more listings and bookings. - Attractive rate rate of only 10% and no fees for gue...
```
